Catalogue admin

Sign in once on each device. Your access key stays in this browser and is only ever sent to GitHub.

  1. Create a key on GitHub. Give it a name and the longest expiry you're comfortable with.
  2. Under Repository access, choose Only select repositories and pick gunnartynes-site.
  3. Under Permissions, add Contents and set it to Read and write. Nothing else is needed.
  4. Generate it, copy it and paste it below.
